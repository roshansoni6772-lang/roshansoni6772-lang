# ChannelPilot ✈️
Command-driven studio for content creators — one app to run your channels: create, schedule, and track content with simple voice/text commands.
## What we're building
- **ChannelPilot Android app** — chat-style commands (Hindi-first) that get production work done
- **ChannelPilot backend** — persistent server that keeps scheduled work running
- Built for YouTube & Instagram creators
*Currently in private development.*
